## 这是什么

一个**课程表**。用浏览器就能打开，可以装到手机桌面，**不需要注册、不需要联网也能用**。

**为什么自己做一个**：现有的中文课程表应用几乎都是安卓原生，iOS 和电脑用户没得用；
而且大多要注册账号、上传数据。这个项目的取舍是——

- **数据只存在你的设备上**，没有任何服务器，不上传、不注册
- **一套代码同时覆盖电脑浏览器、手机浏览器、手机桌面**
- **离线完整可用**（地铁里、断网时照样看课表）

### 为什么没有闹钟

浏览器在后台会被系统"冻结"，网页无法保证锁屏时响铃；系统级闹钟接口只对已安装的原生应用开放。
**这是平台限制，不是实现问题。** 解决办法是用 Capacitor 把同一份代码打包成原生 App，排在 M5。
完整论证见 [`docs/ALARM-STUDY.md`](docs/ALARM-STUDY.md)。

## 快速开始

### 只是想用

直接打开 <https://arrsk.github.io/jiwei/>，或按 `docs/新手使用说明.md` 在自己电脑上跑起来。

### 本地开发

```bash
# 环境：Node.js ≥ 22、pnpm ≥ 9
pnpm install
pnpm dev          # → http://localhost:5273/
```

手机上看效果：`pnpm dev` 会打印 `Network:` 局域网地址，手机连同一 Wi-Fi 打开即可。

一个**必须知道**的坑：本项目数据只存在浏览器里，**建议每学期导出一次备份**
（应用内：齿轮 → 备份与恢复 → 导出备份）。iOS 上浏览器有可能清理本地数据。

## 技术栈

| 层 | 选型 |
| --- | --- |
| 仓库 | pnpm workspace 单仓多包 + TypeScript |
| 前端 | React 19 · Vite 7 · Tailwind CSS v4 · Zustand |

| 部署 | GitHub Actions → GitHub Pages |
| 原生（计划） | Capacitor，复用同一份 `apps/web` 代码 |

## 架构要点

```
apps/web ──────────────► 唯一的客户端（React PWA）
packages/core ─────────► 数据模型 + 时间/周次纯函数（唯一时间真相）
packages/data ─────────► 仓储接口 + 存储引擎（可替换）+ 备份恢复
packages/ui ───────────► 通用组件 + 时间网格基座
packages/platform ─────► 能力适配（通知/闹钟/存储/文件）
```

**三条关键设计**：

1. **`Block` + `Occurrence` 模型**：`Block` 是唯一"占时间"的实体，课表只是 `kind='course'` 的视图。
   这样日程表、任务不需要另建一套并行模型——**加功能 = 加视图，不动核心**。
2. **时间只有一个真相来源**：所有周次、日期、冲突计算都在 `packages/core`，
   任何地方不得自己算日期，否则同一次课在不同界面会算出不同结果。
3. **存储引擎可替换**：业务代码只依赖 `packages/data` 暴露的仓储接口。
   将来从 IndexedDB 换到 SQLite 或接服务端同步，**只换一个入参**，业务代码零改动。

详见 [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) 与 [`docs/DECISIONS.md`](docs/DECISIONS.md)（9 条决策记录，每条都写了"为什么"）。

## 常用命令

```bash
pnpm dev                # 开发服务器（改代码自动刷新）
pnpm build              # 打包到 apps/web/dist
pnpm typecheck          # 类型检查（5 个包）
pnpm test               # 单元测试（136 个）
pnpm smoke              # 构建产物冒烟检查（14 项）
pnpm status             # 一眼看清项目状态
pnpm save "说明"        # 提交并推送到 GitHub
```

排查类脚本：

```bash
node scripts/check-encoding.mjs <文件...>   # 查乱码 / BOM / 注释与标签并成一行
node scripts/check-classes.mjs "<类名>"     # 查某个样式类有没有真的进产物
node scripts/serve-dist.mjs 4173            # 把构建结果开成服务（手机可访问）
node scripts/install-retry.mjs 12           # 网络不稳时反复 install
```

## 开发约定

1. **时间计算只用 `packages/core`**，不要在别处自己算日期。
2. **界面代码不许直接操作数据库**，只走 `packages/data` 的仓储接口。
3. **模块之间不许互相 import**，跨模块协作走 `core` 的类型与 `data` 的仓储。
4. **改完必须验证**：`pnpm typecheck && pnpm test && pnpm build && pnpm smoke`。
