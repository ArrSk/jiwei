# 文件夹说明与文档导航

可以把这个项目理解成四部分：**应用本身、应用共用的零件、说明书、开发工具**。

## 文件夹里到底放了什么

```text
jiwei/
├─ README.md                    项目首页，从这里开始
├─ AGENTS.md                    给开发助手的操作规矩
├─ 启动开发服务器.cmd           双击启动边改边看的版本
├─ 预览成品.cmd                 双击预览打包后的版本
│
├─ apps/web/                    应用本身：你看到的页面
│  ├─ src/                      我们写的程序
│  │  ├─ features/              按功能分房间
│  │  │  ├─ today/              今天页
│  │  │  ├─ timetable/          课程表页和课程编辑
│  │  │  ├─ plan/               计划页
│  │  │  └─ tasks/              待办页
│  │  ├─ shell/                 功能菜单、设置、弹窗等公共外壳
│  │  ├─ shared/                多个页面共用的界面
│  │  ├─ lib/                   小工具、示例数据、配色等
│  │  ├─ modules.tsx            功能名单
│  │  ├─ App.tsx                决定现在显示哪个功能
│  │  ├─ main.tsx               启动程序
│  │  ├─ store.ts               记住正在看哪页、哪张课表等界面状态
│  │  └─ styles.css             颜色、字号、间距和动画
│  ├─ public/                   图标等现成素材
│  └─ dist/                     打包后生成的成品，不在这里手工改页面
│
├─ packages/                    应用共用的四盒零件
│  ├─ core/                     算日期、周次和事项规则
│  ├─ data/                     读写数据、导入、备份和恢复
│  ├─ ui/                       网格、图标等公共界面零件
│  └─ platform/                 文件、安装、通知等设备能力
│
├─ docs/                        说明书，就是你现在看的地方
│  ├─ 项目介绍与规划.md          给你看：做什么，准备怎么发展
│  ├─ 外行人技术与项目架构说明.md 给你看：程序各部分怎样配合
│  ├─ 使用说明.md                给你用：操作、安装、本地启动、排错
│  ├─ AI开发维护文档.md          给我接手：当前入口、注意事项和下一步
│  ├─ HANDOVER.md               每次开发和验证的记录
│  ├─ ARCHITECTURE.md           详细技术设计
│  ├─ ROADMAP.md                M 阶段的执行清单
│  ├─ DECISIONS.md              为什么做这些技术选择
│  ├─ research/                 调研资料：商业、手机、存储、上架
│  └─ history/                  历史资料：环境排错、旧界面版本
│
├─ scripts/                     启动、检查、打包等辅助工具
├─ .github/                     GitHub 自动检查和发布的配置
├─ .git/                        本地版本记录，不要删除
├─ node_modules/                下载来的程序零件，不是我们写的源码
└─ .pnpm-store/                 下载零件的本地缓存
```

`dist`、`node_modules`、缓存和测试输出由工具生成，安装或构建后可能在多个位置出现。同名的 `package.json`、`tsconfig.json`、`index.ts` 分别服务不同的程序包，它们各有用途，不能因为同名就合并。

**你的真实课程、计划和待办存在浏览器里，不在上面这些源码文件夹里。** 复制项目、提交 GitHub 或删除日志都不会替你备份这些数据。要带走数据，请在应用里导出备份。

## 根目录的小文件有什么用

| 文件 | 最直白的解释 |
| --- | --- |
| `package.json` | 需要哪些工具，以及启动、检查、打包命令 |
| `pnpm-lock.yaml` | 把下载零件的版本锁定，保证不同电脑尽量一致 |
| `pnpm-workspace.yaml` | 告诉工具哪些文件夹属于同一个项目 |
| `tsconfig.base.json` | 各部分共用的代码检查规则 |
| `.npmrc` | 下载依赖时使用的设置 |
| `.gitignore` | 哪些缓存、日志、成品不上传 GitHub |
| `.prettierrc.json` | 代码排版规则 |
| `LICENSE` | 开源许可 |
