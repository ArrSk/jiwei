# 第一部分：这个项目是什么

## 1.1 一句话

**「几微」是一个课程表小程序。** 用浏览器打开就能用，手机上可以像 App 一样装到桌面。

## 1.2 现在能做什么

| 功能 | 说明 |
| --- | --- |
| 课程表 | 一周七天、第几节到第几节，点空白格就能加课 |
| 日视图 | 点星期几只看那一天，字更大、教室老师都看得清 |
| 今天 / 下一节 | 打开就告诉你现在在哪上课、下节是什么 |
| 修改课程 | 点课程块直接改，改完不用重录 |
| 多张课表 | 主修 / 辅修 / 新学期各一张，切换互不干扰，各有各的作息 |
| 调课 / 停课 | 某一次课临时取消或改到别的时间，随时恢复原样 |
| 批量编辑 | 一屏内改多门课的星期、节次、周次 |
| 单双周 / 跳周 | 一键单双周；逐周开关点一下就能去掉某一周 |
| 连堂 | 一次课连上好几节（如实验课连上 3 节） |
| 作息时间自己调 | 每节课几点到几点，可以一节一节改 |
| 颜色区分 | 每门课一个颜色，也可以自己指定 |
| 深色模式 | 跟随系统，晚上看着不刺眼 |
| 备份导出 | 把课表导出成一个文件存起来，换设备能恢复 |

## 1.3 还不能做什么（别以为是坏了）

| 功能 | 状态 |
| --- | --- |
| 闹钟（锁屏响铃） | ❌ **浏览器做不到**。需要打包成手机 App 才行，排在以后做 |
| 日程表、笔记、待办 | 还没做，排在以后 |
| 电脑和手机自动同步 | 没有服务器，所以不会自动同步。用「导出备份 → 导入备份」搬 |
| 多人共用 / 登录 | 没做，也没打算做（这是自己用的工具） |

## 1.4 几个名词

| 名词 | 什么意思 |
| --- | --- |
| **PWA** | "网页应用"。就是网页，但能像 App 一样装到手机桌面，还能离线打开 |
| **浏览器本地存储** | 数据存在你自己的浏览器里，**不在任何服务器上** |
| **备份文件** | 一个 `.json` 结尾的文件，里面装着你课表的全部数据 |
| **构建 / 打包** | 把源代码"翻译"成浏览器能直接运行的版本 |
| **开发服务器** | 一边改代码一边自动刷新预览的东西，只在你自己电脑上 |
| **终端 / PowerShell** | Windows 上输入命令的地方。开始菜单搜「PowerShell」就能打开 |
| **局域网** | 你家的 Wi-Fi。手机连同一个 Wi-Fi 才能访问电脑上的东西 |

# 第二部分：开始之前要装什么

> 如果你就是**打开来用**（不改代码），只需要装 Node.js 这一样。

## 2.1 必装：Node.js

**它是什么**：让电脑能运行这个项目的软件（类似"运行环境"）。

**怎么装**：

1. 打开 https://nodejs.org/
2. 下载 **LTS 版本**（左边那个，写着 LTS）
3. 一路点「下一步」装完
4. **装完要重启一次电脑**（或者至少关掉所有终端窗口）

**怎么确认装好了**：打开 PowerShell，输入下面这行按回车：

```powershell
node -v
```

如果显示类似 `v24.18.0` 这样的版本号，就成功了。如果提示"不是内部或外部命令"，说明没装好或没重启。

## 2.2 必装：pnpm

**它是什么**：负责"下载项目需要的零件"的工具。项目用到的零件有几百个，靠它自动下载。

装好 Node.js 之后，在 PowerShell 里输入：

```powershell
corepack enable
corepack prepare pnpm@latest --activate
```

确认：

```powershell
pnpm -v
```

显示版本号就成功了。

## 2.3 你电脑上已经有的（不用装）

- **Node.js**：已装（v24.18.0）
- **pnpm**：已装（11.8.0）
- **git**：已装

# 第三部分：第一次运行

## 3.1 下载零件（只需做一次）

打开 PowerShell，逐行复制粘贴、每行按回车：

```powershell
cd E:\CodeAndProj\jiwei
pnpm install
```

**这一步在做什么**：下载项目需要的所有零件到 `node_modules` 文件夹。第一次会比较慢（几分钟）。

> **如果失败或卡住**：这台电脑的网络连国外服务器不太稳定。改用这个命令重试（会自动反复试到成功）：
> ```powershell
> node scripts/install-retry.mjs 12
> ```

## 3.2 启动，看效果

```powershell
pnpm dev
```

**看到什么**：屏幕上会出现类似这样的几行

```
  VITE v7.3.6  ready in 489 ms
  ➜  Local:   http://localhost:5273/
  ➜  Network: http://192.168.0.104:5273/
```

**然后**：按住 Ctrl 点那个 `http://localhost:5273/`，浏览器就会打开课表。

**怎么关掉**：回到 PowerShell 窗口，按 `Ctrl + C`。

## 3.3 第一次打开会看到什么

- 一个空的课程表（左边是节次和时间，上面是周一到周日）
- 中间写着「课表还是空的」，有两个按钮：**添加第一门课** / **载入示例课表**

**建议先点「载入示例课表」** —— 会填进 9 门示例课程，你能立刻看到样子，觉得不合适可以整门删掉。

# 第四部分：平时怎么用

> 这一部分只讲**和"在电脑上跑起来"相关**的操作。
> 每个功能（日视图、多张课表、调课停课、批量编辑、跳过某几周等）的详细用法，
> 统一写在 [`使用说明.md`](使用说明.md) 里，不在这里重复 ——
> 那份文档才是给"用的人"看的，两边都写一遍迟早会不一致。

## 4.1 加一门课

1. 点右下角蓝色的「**添加课程**」按钮（或直接**点课表里的空白格子**，会带上星期和节次）
2. 从底部滑上来一个面板，填：
   - **课程名**（必填）
   - 教师、教室（选填）
   - **星期**：下拉选周几
   - **节次**：选从第几节到第几节
   - **颜色**：点一个小圆点，或选「自」让它自动配
   - **周次**：点「全周 / 单周 / 双周」，或在下面输入框自己写 `1-16`、`1,3,5`；
     下面那排数字可以**点一下去掉某一周**（比如第 5 周实习不上）
3. 点「**保存**」

## 4.2 删一门课

往下滚，找到「**全部课程**」列表，点右边的垃圾桶图标。

> 想**修改**课程不用删了重加：直接点课表里那个课程色块就能改。
> 删课也可以在编辑表单左下角点「删除」。

## 4.3 切换周次

课表上方中间的「**第 N 周**」两边有 `<` `>` 按钮，点了翻周。

## 4.4 改作息时间（几点上课）

点右上角**齿轮** → 「**作息时间**」：

- **每节时长 / 课间休息**：这两个是"一键重排"用的快捷参数
- **上午 / 下午 / 晚上的起始时间和节数**：改完点右边的「重排」，那一段就按等间隔重排
- **每节起止时间**（表格）：**这里可以一节一节精确改**
- 底部：「+ 增加一节」「− 删除最后一节」
- 改完点「**保存并重建课表**」

> 为什么两种方式都有：有些学校作息是规整的（45 分钟一节、课间 5 分钟），点"重排"最快；
> 但真实作息常常不规整（比如第 3 节前休 15 分钟、中午午休），那种就得在表格里一节节改。

## 4.5 备份（**建议每学期做一次**）

点右上角**齿轮** → 「**备份与恢复**」→ 点「**导出备份**」。

浏览器会下载一个 `jiwei-backup-2026-09-26.json` 这样的文件。

**这个文件就是你课表的全部数据。** 请把它存到网盘或发给自己。

**怎么恢复**：同一位置点「从备份恢复」→ 选那个文件 → 会先给你看"这个备份里有什么" → 点「确认覆盖」。

> ⚠️ **为什么这件事很重要**：你的课表**只存在这台设备的浏览器里**，没有服务器备份。
> 而手机浏览器（尤其 iPhone）**有可能自己清理掉本地数据**。到时候除了这个文件，没有别的东西能救回来。

## 4.6 手机上用

**第一步**：让这个程序在你电脑上跑着（`pnpm dev` 或后面第五节的命令都行）

**第二步**：查你电脑的局域网地址。最直接的办法是**看 `pnpm dev` 打印出来的那行 `Network:`**。

如果忘了，在 PowerShell 里输入：

```powershell
ipconfig
```

在输出里找「**IPv4 地址**」那一行，形如 `192.168.0.104`。

**第三步**：**手机连上同一个 Wi-Fi**（重点：必须同一个）

**第四步**：手机浏览器打开 `http://电脑的IP:5273/`，例如 `http://192.168.0.104:5273/`

**第五步**（推荐）：装到桌面
- **iPhone**：Safari 打开 → 底部「分享」按钮 → 「添加到主屏幕」
- **安卓**：Chrome 打开 → 右上角三个点 → 「添加到主屏幕」

装到桌面后就是一个全屏的应用，看起来和真 App 一样。

> **注意**：电脑的 IP 地址**会变**（路由器重新分配）。今天能用的地址，明天可能就不行了。
> 遇到打不开，重新查一次 IP 就行，不用重装任何东西。

# 第五部分：给小白的几个操作提醒

## 5.1 打不开手机地址怎么办

按顺序检查：

1. **IP 是不是变了** → 重新 `ipconfig` 查
2. **手机和电脑是不是同一个 Wi-Fi** → 关掉手机流量，只连 Wi-Fi
3. **防火墙挡住了**（最常见）：
   - 开始菜单搜「**Windows Defender 防火墙**」
   - 左边点「**允许应用或功能通过 Windows Defender 防火墙**」
   - 点「**更改设置**」
   - 找到「**Node.js**」，把「**专用**」那列打钩
   - 如果列表里没有，点「允许其他应用」→ 浏览到 `E:\nodejs\node-v24.18.0-win-x64\node.exe`

> 这只在你家局域网里开放，外网访问不到，不是把电脑暴露出去。

## 5.2 改完代码没生效

- 先看 PowerShell 窗口有没有**红色的报错**
- 有报错就把报错内容完整复制给别人看
- 没报错但界面没变，在浏览器按 `Ctrl + F5` 强制刷新

## 5.3 不小心把数据弄没了

**先别慌，别乱点。** 依次尝试：

1. 打开浏览器按 `F5` 刷新（可能只是没显示出来）
2. 换个方式确认：地址后面加 `/#` 再打开
3. 如果你**导出过备份**：齿轮 → 备份与恢复 → 从备份恢复
4. 都没用 → 数据确实没了，只能重新录

## 5.4 哪些命令是"看一眼状态"的（不会改任何东西）

```powershell
node -v          # 看 Node.js 版本
pnpm -v          # 看 pnpm 版本
ipconfig         # 看本机 IP 地址
git log --oneline # 看改过哪些版本
```

## 5.5 重要提醒：别删这些文件夹

| 文件夹 | 里面是什么 | 删了会怎样 |
| --- | --- | --- |
| `node_modules` | 下载的零件 | 页面上打不开，要重跑 `pnpm install`（能恢复，但慢） |
| `.git` | 所有历史版本 | **彻底失去回退能力**，无法找回任何旧版本 |
| `docs` | 说明文档 | 说明没了（不影响程序运行） |

# 第六部分：数据在哪里（重点）

## 6.1 你的课表存在哪

**存在你打开课表的那个浏览器里**，不在任何服务器上。

具体位置：

| 平台 | 数据在浏览器的什么地方 |
| --- | --- |
| 电脑 Chrome / Edge | 「网站数据 / IndexedDB」 |
| 手机浏览器 | 同上，但是你自己手机的浏览器里 |

## 6.2 这意味着什么（**请认真看**）

**好处**：
- 不需要注册、不需要联网、打开就能用
- 你的课表不会被任何公司看到

**代价**：
- 数据**只在那一台设备的那个浏览器里**
- 手机上的课表和电脑上的课表**是两份，不会同步**
- 浏览器**有可能自己清理掉**（iPhone 上这种情况时有发生）

## 6.3 所以必须做的事

**每学期导出一次备份**（第四节 4.5 讲的方法），存到你自己的网盘或微信收藏。

这是目前**唯一**的保险。

> 为什么会这样：这个项目当初设计成"不需要服务器"，好处是零成本零维护，
> 代价就是没有云端备份。以后如果要换设备自动同步，需要另外开发（排在很后面）。

# 第七部分：常见问题

**Q：会收费吗？**
不会。这个项目没有服务器，不需要花钱。

**Q：需要联网吗？**
只有第一次下载零件时和推送代码到 GitHub 需要。平时用课表**完全不需要联网**。

**Q：我的课表会被别人看到吗？**
不会。数据只在你设备的浏览器里，没有任何上传功能。

**Q：能装成真正的 App 上应用商店吗？**
技术上可以（叫 Capacitor 的方案），但要装开发环境、还要应用商店账号，目前没做。

**Q：为什么闹钟做不了？**
因为浏览器在后台会被系统"冻结"，网页没法保证锁屏时响铃。这是浏览器的限制，不是代码没写好。要做必须打包成真正的手机 App。

**Q：改坏代码了想恢复怎么办？**
项目用 git 保存了所有历史版本。找懂技术的人（或让 AI）执行"回退到某个版本"就行。**所以别删 `.git` 文件夹。**

**Q：手机和电脑的课表能同步吗？**
现在不能。可以手动导出备份再在另一台设备导入。

# 第八部分：想改代码时要知道的

> 这一段有点技术性，**不看也不影响使用**。

## 8.1 项目是怎么组织的

```
jiwei/
├─ apps/web/          网页界面（你能看到的部分）
├─ packages/
│  ├─ core/           ★ 课程表的核心规则：日期、第几周、课程怎么重复
│  ├─ data/           ★ 数据怎么存、怎么读、怎么备份
│  ├─ ui/             通用界面零件（表格、图标）
│  └─ platform/       判断"这台设备能做什么"（比如能不能响闹钟）
├─ docs/              各种说明文档
└─ scripts/           一些小工具脚本
```

带 ★ 的两个是核心。**改界面一般只动 `apps/web`。**

## 8.2 几条重要规矩（改代码时必须守）

1. **所有时间计算必须用 `packages/core` 里的函数**
   不要自己写"今天是第几周"这种逻辑。必须只有一个地方算时间，否则两处算出不同结果，课表就会错。

2. **界面代码不许直接操作数据库**
   要用 `packages/data` 提供的接口。这样以后换存储方式时，只改一个地方。

3. **课程表模块不许引用别的模块**
   以后会加日程表、笔记等模块，它们之间不能互相 import。

## 8.3 改完代码怎么验证

```powershell
pnpm typecheck     # 检查代码有没有明显错误（不改任何文件）
pnpm test          # 跑自动化测试（现在有 136 个）
pnpm build         # 打包成正式版本
node scripts/smoke.mjs   # 检查打包后的产物是否完整
```

## 8.4 本项目踩过的坑（别再踩）

| 坑 | 教训 |
| --- | --- |
| **Tailwind 扫不到子包的样式** | 在 `packages/ui` 里写的样式类，如果没在 `apps/web/src/styles.css` 里用 `@source` 声明，**根本不会生成**。症状是"改了没反应" |
| **PowerShell 改文件把中文写成乱码** | Windows 的 PowerShell 读写文件默认不是 UTF-8。**改代码要用编辑器或专门的工具**，不要用 `Set-Content` |
| **`.gitignore` 里的 `data/` 会连 `packages/data` 一起忽略** | 要写 `/data/`（前面加斜杠，只匹配根目录） |
| **服务器只绑 127.0.0.1 手机连不上** | 要绑 `0.0.0.0`。这是 `scripts/serve-dist.mjs` 曾经的问题 |
| **IP 地址会变** | 别把 IP 写死在任何地方 |

