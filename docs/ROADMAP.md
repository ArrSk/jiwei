# 几微 · 路线图

> 原则：**每个里程碑结束都要能真实用起来**——不做"只有内部进展、用户看不到东西"的阶段。
> 纪律：实现 M(n) 时**不写**任何 M(n+1) 的业务逻辑，只使用已就位的模型与接口。
> 相关文档：[架构设计](ARCHITECTURE.md) · [决策记录](DECISIONS.md) · [新手使用说明](新手使用说明.md)

---

## 里程碑总览

| 阶段 | 主题 | 交付 | 你能体验到什么 |
| --- | --- | --- | --- |
| **M0** | **最小可用课表** | 单仓骨架 + 完整数据模型 + 手动录课 + 简易周视图 + 本地持久化 | ✅ **电脑和手机上真的能看到自己的课表** |
| **M1** | 课表完整版 | 单双周/跳过周/连堂/调课、表格批量编辑、日视图 + 今天卡片 | 真实学期的复杂课表也能正确显示 |
| **M2** | 手机可用 | PWA 可安装、离线完整可用、深色模式、当前周高亮 | 加到手机桌面像原生 App，飞行模式可看 |
| **M3** | 数据进出 | CSV/JSON 导入导出 + **iCal 日历订阅** | 手机系统日历订阅；换设备靠 JSON 备份还原 |
| **M4** | 日程表 | 月历/时间轴视图 + 手动加事件（全天、跨天、重复） | 能记"周三 14:00 开会""10月8日交材料" |
| **M5** | 闹钟 / 提醒 | 提醒规则 + 应用内提醒 → **Capacitor 原生外壳 + 本地通知闹钟** | 上课/截止前按设定提前量收到提醒；原生包能锁屏响铃 |
| **M6** | 任务 | 待办列表 + 截止日 + 完成勾选 + 冲突提示 | 能看到"最近要交的作业" |
| **M7** | 笔记 | 三种粒度（单次课/整门课/独立）+ Markdown + **全文搜索** | 边上课边记，按关键词找回 |
| **M8** | 多设备/分享（可选） | 服务端同步 或 分享链接 或 CalDAV 对外协议 | 手机和电脑数据一致 |

> **阶段划分原则**：M0 是**垂直切片**（每层都碰、都跑通、但都只做最少），M1 才是**把课表做完整**。
> 这样第一周就能验证"模型 → 存储 → 渲染"整条链路，架构问题早暴露，而不是等全部写完才发现。

## M0 · 最小可用课表（目标：让你尽快真实用起来）

**你最终能做的事**：打开网页 → 建个学期 → 添几门课 → **看到周视图课表**；手机上打开同一地址也能看到；关掉重开数据还在。

### A. 地基
- pnpm workspace + TypeScript 严格模式；`apps/web`、`packages/{core,data,ui,platform}`
- Vite + React 19 + Tailwind v4 + 路由 + 深色模式骨架
- ESLint 规则：禁止 `features/*` 直接 import Dexie（接口隔离的强制执行）
- **完成标准**：`pnpm dev` 启动，控制台打印"存储已就绪、schema 版本 N"

### B. 模型与存储（**完整**，不缩水）
> 模型是全局最贵的部分，M0 一次做全，后续里程碑不再改结构、不再迁移数据。

- `@jiwei/core`：**完整的** Zod schema（`Semester`/`Period`/`Block`/`Occurrence`/`Alert`/`Note`/`Meta`）
- `@jiwei/core`：`materialize()` 与周次/日期纯函数（`expandWeeks`/`currentWeek`/`nextOccurrence`）+ 单测
- `@jiwei/data`：仓储接口 + Dexie 引擎实现 + schema 版本迁移（幂等）

### C. 课表功能（**最小**，只做能跑通闭环的部分）
- 学期：名称、起始日（第 1 周周一）、总周数
- 作息：默认一套常见作息（第 1~12 节），先不做编辑界面
- 录课：一门一门添加（名称、老师、地点、颜色、星期、起止节次、周次)
- 周视图：`TimeGrid` 网格渲染 + 左右切周
- 本地持久化
- **暂不做**：单双周/跳过周的录入界面（模型已支持，先用全周）、连堂的拖拽、表格批量编辑、日视图、调课

### D. 完成标准
- 电脑浏览器可访问，手机浏览器打开同一地址（局域网 IP）也能看到课表
- 添加的课程**刷新/重开后仍在**（本地库生效）
- `materialize()` 与周次计算有单测覆盖
- 断网状态下页面仍能打开（本地优先的初步验证）

## M1 · 课表完整版

**功能（在 M0 基础上补齐）**
- 课程录入补全：单双周、跳过指定周、连堂（起止节次跨多节）、复制周次
- 表格/批量编辑：一屏内改多门课
- **日视图**：手机默认；"今天"卡片显示当前/下一节课与倒计时
- **当前周高亮**
- 调课/停课（`Adjustment`）
- 作息时间表编辑界面

**架构要求**
- 网格用 `@jiwei/ui` 的通用 `TimeGrid`（不是课表专用）
- 页面来自 `features/timetable` 导出的 `FeatureModule`，外壳负责导航
- 所有时间计算调用 `@jiwei/core/materialize`，模块内不出现日期算法

**完成标准**
- 真实学期课表（含单双周、跳过周、连堂、调课）显示正确
- 单双周、跳过周、连堂、调课都有单测覆盖

## M2 · 手机可用

- PWA manifest + Service Worker（应用壳预缓存，数据来自本地库）
- iOS/Android"添加到主屏幕"引导页
- 深色模式、字号/密度设置
- 持久化存储申请（`navigator.storage.persist()`）+ 存储用量提示
- **完成标准**：手机加到桌面后全屏打开，飞行模式下能看课表

## M3 · 数据进出

- 导出：**JSON 全量备份**（关键）、CSV、**iCal 订阅 URL**
- 导入：JSON 备份还原、CSV 粘贴、WakeUp / 时光课程表导出文件兼容
- 导入向导：解析预览 → 冲突提示 → 确认写入
- **完成标准**：手机系统日历订阅后能看到全部课程；换设备用 JSON 备份可完整还原

## M4 · 日程表

- 月历 + 时间轴视图（复用 `TimeGrid` 与列表组件）
- 手动添加事件：绝对时刻、全天、跨天、简单重复（每周/单双周/每月）
- 与课表同屏叠加（今天/本周既有课也有日程）
- **完成标准**：能把"周三 14:00 开会""10月8日交材料"记录进去，并与课表统一展示

## M5 · 闹钟与提醒

- `Alert` 规则 UI：提前量（0/5/10/15/30/60 分钟）、范围（仅本周/长期）
- Web 通道：应用内提醒 + iCal（含提醒偏移）；能力不足时诚实降级
- **原生通道**：Capacitor 外壳 + `@capacitor/local-notifications`，Android 走 `AlarmManager`
- 权限引导、电池优化白名单引导、滚动排程（应对 iOS 64 条上限）
- **前置条件**：Android Studio / Xcode 环境（见 [`ALARM-STUDY.md`](ALARM-STUDY.md)）
- **完成标准**：Android 真机上杀掉应用后，闹钟仍按时响铃

## M6 · 任务（待办）

- 列表视图 + 截止日 + 完成勾选 + 逾期高亮
- 首页 widget"最近要交的作业"
- 与日程/课表统一时间线展示

## M7 · 笔记

- 三种粒度：某一次课（`occurrence`）、整门课（`block`）、独立笔记（`standalone`）
- Markdown 编辑 + 预览；原文存 IndexedDB，另支持导出 Markdown 文件夹（可被 Obsidian/git 管理）
- 全文搜索：**内存倒排索引 + 分词**（数据量小够用）；统一搜索入口（课、事件、笔记、任务）
- 迁移到 SQLite 后改用 FTS5，接口不变

## M8+ · 可选方向

| 方向 | 触发条件 | 说明 |
| --- | --- | --- |
| 多设备同步 | 需要在手机/电脑间同步 | 启用 `apps/api`；`@jiwei/data` 新增"远程仓储实现"，**接口不变**；引入账号（better-auth）与冲突合并 |
| 迁移到 SQLite | 复杂查询变难写 / 笔记搜索要求变高 / 决定接同步 | 只替换 `packages/data/src/engines/`（ADR-003 触发条件） |
| Web Push | 需要在应用关闭时收到提醒（桌面端/Android） | 需要服务器 + VAPID 密钥 |
| 分享课表 | 想把课表发给同学 | 静态图片导出 或 只读分享链接 |
| CalDAV 对外协议 | 想让第三方客户端直接读写 | `Block` 模型即现成的映射源 |
| 教务系统导入 | 手动录入太烦 | `parsers/njupt.ts`，接受随学校改版维护的成本 |

## 里程碑纪律

1. **一次只加一个模块**；M1 冻结期间不插队。
2. 每个里程碑结束都要能**真实用起来**，不做"半成品功能堆积"。
3. 任何"顺手也能做"的功能记入 Backlog，**不进入当前里程碑**。
4. 模型改动必须回写 [`ARCHITECTURE.md`](ARCHITECTURE.md) 第 4 节与 [`DECISIONS.md`](DECISIONS.md)。
