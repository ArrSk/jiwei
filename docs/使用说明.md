# 几微 使用说明

> **这份说明不需要你懂任何编程知识。**
> 你不用安装任何软件，也不用注册账号 —— 用浏览器打开一个网址就能用。

---

## 一、这是什么

「几微」是一个**课程表**。它长这样：

- 打开就是一个七天的表格，横着是周一到周日，竖着是第 1 节到第 12 节；
- 你的课就摆在对应的格子里，一门课一个颜色；
- **不需要注册、不需要登录**；
- 你的课表数据**只存在你自己的手机/电脑里**，不会上传到任何地方。

网址（建议收藏）：

**<https://arrsk.github.io/jiwei/>**

---

## 二、怎么打开它

### 方式 1：电脑上打开

用 Chrome、Edge、Safari 都行，把网址粘进地址栏，回车。

### 方式 2：手机上打开

手机浏览器同样粘这个网址。打开后建议做一步：

- **iPhone（Safari）**：点底部中间的「分享」按钮 → 往下找到「**添加到主屏幕**」→ 添加
- **安卓（Chrome）**：点右上角「⋮」→「**添加到主屏幕**」/「安装应用」

加完之后桌面上会多一个图标，点它打开就是**全屏**的，没有浏览器地址栏，
跟装了一个 App 一模一样。

> **为什么一定要加到主屏幕？**
> 一是好用（全屏、图标直达）；二是**更不容易丢数据** ——
> 手机浏览器会定期清理"只是网页"的本地数据，但"已经装到桌面"的会被当作 App 保留。

## 三、第一次打开：三步就能用起来

打开后你会看到一个空的课表，**已经帮你建好了一张「2026 秋」**，不用你去设置什么。

### 第 1 步：加一门课

**点课表里的任意空白格子**（比如"周三 第 3 节"那一格），下面会滑出一个表单：

| 填什么 | 说明 |
| --- | --- |
| 课程名 | 比如「高等数学A（I）上」。**只有这一项是必填的** |
| 老师 | 比如「张建国」 |
| 教室 | 比如「教三 201」 |
| 周次 | **留空就代表每周都上**（最常用）。要单双周或跳过某周见下面第五节 |
| 颜色 | 点一下色块就能换，不选也行（会自动配一个） |

填完点右下角「**保存**」。课就出现在表格里了。

> 不想一条条录？点表格上方的「**载入示例课表**」可以先把 9 门假课放进去看看效果，
> 之后在「全部课程」里删掉就行。

### 第 2 步：看课表

- **左右翻周**：点顶部中间的 `‹ 第 1 周 ›` 两边的箭头。
- **回到本周**：点一下「第 N 周」这几个字就跳回本周。
- **今天的课**：今天的日期会被**填成蓝色**，一眼就能找到。
- **想看清某一天的课**：**点星期几那几个字**（比如「三」），就进入"只看这一天"的大字模式，再点左上角「← 整周」回来。

### 第 3 步：装到手机桌面

见上面「方式 2」。做完这步就可以日常用了。

## 四、八个最常用的操作

### 1. 改一门课

**点表格里那门课的色块** → 表单会带着原来的内容滑出来 → 改完点「保存」。

> 改的是**这一门课的所有周次**。只想动某一天，看下面第 3 条。

### 2. 删一门课

点课程块 → 表单左下角「**删除**」。

或者：表格下方展开「**全部课程（N）**」→ 点那一行右边的垃圾桶图标。

### 3. 某一次课停了 / 调到别的时间

比如"这周三的高数老师出差停一次"、"下周一的高数调到周五"。

1. **点星期几进日视图**（比如点「三」）；
2. 找到那一节课，点它**右边那个「⋯ 调/停」**；
3. 选一个：
   - **停课（这一天的这一次）** —— 那节课会灰掉划线，表示不上了；
   - **改到别的日期 / 节次** —— 选个新日期和节次，点「保存改期」；
4. **随时可以恢复**：再点一次那个「⋯ 已调整」→「**恢复原样**」。

> 这里改的**只有这一次**，这门课其他周次不受影响。

### 4. 一次改好几门课

表格下面展开「**全部课程（N）**」→ 点「**批量编辑**」。

弹出的列表里，每门课都能直接改**课程名、星期、起止节次、周次**。
改过的行会高亮，右下角会写「保存全部（3）」告诉你改了几门。改完点它即可。

> 中途点「取消」什么都不会保存。

### 5. 单双周 / 跳过某几周

在添加或编辑课程的表单里，找到「周次」下面的**一排数字**（1 2 3 … 20）：

- **蓝色的** = 那一周要上课；**灰色划掉的** = 那一周不上；
- **点一下**数字就能切换。比如第 5 周要去实习，点一下「5」把它划掉就行。

上面还有三个快捷键：

| 按钮 | 意思 |
| --- | --- |
| 全周 | 每周都上（周次框留空） |
| 单周 | 1、3、5、7… 周上 |
| 双周 | 2、4、6、8… 周上 |

### 6. 改上课时间

比如你们学校第 1 节是 8:30 开始，不是 8:00。

**功能 → 设置 → 课表设置 → 作息时间** → 直接改每一节的开始/结束时间 → 保存。

> 改完之后，**课表里所有课的时间会跟着变**，不用一门门改。
> 注意：**每张课表有自己一套作息**（见下一条）。

### 7. 建第二张课表（主修 / 辅修 / 新学期）

1. 点**左上角课表的名字**（比如「2026 秋 ▾」）；
2. 面板里可以：
   - **新建课表** —— 起个名字、填开学日期（第 1 周的周一）和总周数；
   - **切换课表** —— 点一下那一行就切过去了；
   - **改名 / 改周数** —— 点那一行右边的「设置」；
   - **删除** —— 点「删除这张课表」，会再问你一次（删了就找不回来了）。

> 每张课表的课和作息都是**各管各的**，切过去只看那一张。

### 8. 备份（**很重要，请务必看**）

**你的课表只存在你这台设备的浏览器里。** 换手机、清缓存、浏览器出问题，都可能丢。

所以：**每学期导出一次备份**。

**功能 → 设置 → 备份与恢复 → 导出备份** → 会下载一个 `.json` 文件，
存到网盘 / 微信收藏 / 邮箱都行。

换设备时：新设备打开同一个网址 → 功能 → 设置 → 备份与恢复 → **导入备份** → 选那个文件。

## 五、常见问题

**问：我换个手机 / 换台电脑，课表会自动同步过去吗？**

不会。这个应用**没有服务器**，数据不联网、不上传，所以也就没法自动同步。
用上面第 8 条的「导出备份 → 导入备份」搬过去。

**问：会不会有人看到我的课表？**

不会。数据只在你自己设备的浏览器里，我们这边没有你的任何数据，连你用过都不知道。

**问：为什么没有闹钟？上课前能提醒我吗？**

**闹钟暂时没有，而且浏览器版本做不到** —— 这不是没做，是浏览器的限制：
网页在后台会被系统"冻结"，锁屏时无法保证响铃（微信的消息推送也一样会延迟）。
系统级闹钟只对**已安装的原生 App**开放。

解决办法是把同一份代码打包成安卓 App，排在后面做。到时候安卓手机上可以锁屏响铃。
详见 [ALARM-STUDY.md](research/ALARM-STUDY.md)。

**问：我的课表不见了 / 变成空的了！**

先别慌，按顺序试：

1. 检查网址是不是 <https://arrsk.github.io/jiwei/>（结尾要有 `/jiwei/`）；
2. 换回**之前用的那个浏览器**（在 Chrome 里加的课，用 Safari 打开是看不到的）；
3. 手机浏览器如果开过"无痕/隐私模式"，关掉重开 —— 无痕模式关掉就会清空；
4. 如果之前导出过备份，直接「导入备份」恢复；
5. 都没有的话……这就是为什么第 8 条要求你**定期导出备份**。

**问：页面打开是白的 / 一直转圈？**

1. 刷新一下（电脑上按 `F5`，手机上从顶部下拉）；
2. 换个网络试试（有些校园网会拦截陌生网站）；
3. 用 Chrome / Edge / Safari，不要用很老的浏览器或某些 App 内置的浏览器。

**问：加到手机桌面后，点图标打不开（白屏 / 报错 / 跳到别的页面）？**

先确认一件事：**你是从 Safari 里"添加到主屏幕"的吗？**
微信、QQ、抖音里打开网页后加的图标，用的是它们自己的浏览器，不一定能正常工作。

如果打开后显示 **404**，请按下面的方法处理：

1. 用 **Safari** 在地址栏输入完整网址 <https://arrsk.github.io/jiwei/>，确认能看到课表。
2. 刷新页面，等待加载完成；修复刚发布时可再关闭该标签页并重新打开。
3. 从这个页面点「分享」→「添加到主屏幕」。添加窗口只显示域名时，不必在那里补写 `/jiwei/`；应先在 Safari 地址栏打开完整网址。
4. 打开新添加的图标，确认能进入课表。旧图标先保留；已有课表时先导出备份再考虑移除旧图标。

> **原因**：旧版安装配置把启动地址写成 `/`，图标会打开 `https://arrsk.github.io/`，
> 这个根目录返回 404。正确课表地址是 `/jiwei/`；修复后的安装配置使用相对启动地址 `./`。
> 旧图标可能仍保留原启动地址，因此发布修复后还需要重新添加。
>
> **请勿为了处理 404 清除 Safari 网站数据**。课表保存在本机，清除网站数据会删除它；
> Safari 与主屏幕应用也可能使用不同的存储环境，重新添加后不要假设课表一定自动迁移。

**问：文字变成"锟斤拷"这种乱码？**

先刷新并记录报错；已有数据时先导出备份，再排查文件或缓存。不要直接清除网站数据，这可能删除本地课程。

**问：能分享给同学吗？**

把网址发给他就行，他自己打开、自己录自己的课表，互相看不到。
"一键分享课表给同学"这个功能排在后面做。

**问：字太小 / 想要深色模式？**

- 深色模式**跟随你手机/电脑的系统设置**（系统切换夜间模式，它就跟着变）；
- 手机上字太小的话，点星期几进**日视图**，字会大很多。

**问：这软件收钱吗？会弹广告吗？**

不收钱，没有广告，也没有任何账号系统。它是开源的（MIT 许可），代码全部公开。

## 六、名词对照表

不懂编程的人只需要认识这几个词：

| 词 | 大白话 |
| --- | --- |
| **课表 / 学期** | 界面上的「课表」= 一套课程安排。一个学期就是一张课表 |
| **教学周 / 第 N 周** | 开学第一周算第 1 周。第 8 周就是开学第 8 周 |
| **单周 / 双周** | 隔一周上一次：单周是 1、3、5… 双周是 2、4、6… |
| **连堂** | 一次课连上好几节，比如实验课连上 3 节 |
| **日视图** | 只看某一天的大字模式。点星期几进入 |
| **备份文件** | 一个 `.json` 结尾的文件，里面装着你课表的全部数据 |
| **PWA / 添加到主屏幕** | 把网页变成手机桌面上的一个图标，打开是全屏的 |
| **浏览器本地存储** | 数据存在你自己设备里，不在服务器上 |
| **清缓存** | 浏览器"清理空间"，**有可能连你的课表一起清掉**，所以要先备份 |

## 本地运行

原“新手使用说明”中的启动和手机访问方法已合并到这里。文件夹含义见 [文档导航](README.md)。

### 第二部分：开始之前要装什么

> 只打开线上网址不需要安装这些工具。只有在自己电脑运行项目时才需要 Node.js 和 pnpm。Node.js 要求 22 或以上；pnpm 版本以根目录 package.json 的 packageManager 为准，当前为 11.8.0。

#### 2.1 必装：Node.js

**它是什么**：让电脑能运行这个项目的软件（类似"运行环境"）。

**怎么装**：

1. 打开 https://nodejs.org/
2. 下载 **LTS 版本**（左边那个，写着 LTS）
3. 一路点「下一步」装完
4. **装完要重启一次电脑**（或者至少关掉所有终端窗口）

**怎么确认装好了**：打开 PowerShell，输入下面这行按回车：

```powershell
node -v
```

如果显示类似 `v24.18.0` 这样的版本号，就成功了。如果提示"不是内部或外部命令"，说明没装好或没重启。

#### 2.2 必装：pnpm

**它是什么**：负责"下载项目需要的零件"的工具。项目用到的零件有几百个，靠它自动下载。

装好 Node.js 之后，在 PowerShell 里输入：

```powershell
corepack enable
corepack prepare pnpm@11.8.0 --activate
```

确认：

```powershell
pnpm -v
```

显示版本号就成功了。

### 第三部分：第一次运行

#### 3.1 下载零件（只需做一次）

打开 PowerShell，逐行复制粘贴、每行按回车：

```powershell
cd E:\CodeAndProj\jiwei
pnpm install
```

**这一步在做什么**：下载项目需要的所有零件到 `node_modules` 文件夹。第一次会比较慢（几分钟）。

> **如果下载失败或卡住**：先看实际报错。网络不稳定时，改用这个命令重试（会自动反复试到成功）：
> ```powershell
> node scripts/install-retry.mjs 12
> ```

#### 3.2 启动，看效果

```powershell
pnpm dev
```

**看到什么**：屏幕上会出现类似这样的几行

```
  VITE v7.3.6  ready in 489 ms
  ➜  Local:   http://localhost:5273/
  ➜  Network: http://<局域网IP>:5273/
```

**然后**：按住 Ctrl 点那个 `http://localhost:5273/`，浏览器就会打开课表。

**怎么关掉**：回到 PowerShell 窗口，按 `Ctrl + C`。

#### 3.3 先体验示例

默认进入今天页。点击示例导入，再从底部“功能”打开课程表、计划和待办；开关在设置里。示例会写入当前本地数据库，可以编辑或删除。


### 用手机访问电脑上的版本

**第一步**：让这个程序在你电脑上跑着（`pnpm dev` 或下面的成品预览命令都行）

**第二步**：查你电脑的局域网地址。最直接的办法是**看 `pnpm dev` 打印出来的那行 `Network:`**。

如果忘了，在 PowerShell 里输入：

```powershell
ipconfig
```

在输出里找「**IPv4 地址**」那一行，记为 `<局域网IP>`。

**第三步**：**手机连上同一个 Wi-Fi**（重点：必须同一个）

**第四步**：手机浏览器打开 `http://电脑的IP:5273/`，例如 `http://<局域网IP>:5273/`

局域网 HTTP 地址主要用于临时体验；安装与离线缓存请用已部署的 HTTPS 地址验收，不能把局域网能打开当成安装离线验收。电脑关闭服务后，这个临时链接就不能继续访问。


### 打不开手机地址怎么办

按顺序检查：

1. **IP 是不是变了** → 重新 `ipconfig` 查
2. **手机和电脑是不是同一个 Wi-Fi** → 关掉手机流量，只连 Wi-Fi
3. **防火墙挡住了**（最常见）：
   - 开始菜单搜「**Windows Defender 防火墙**」
   - 左边点「**允许应用或功能通过 Windows Defender 防火墙**」
   - 点「**更改设置**」
   - 找到「**Node.js**」，把「**专用**」那列打钩
   - 如果列表里没有，点「允许其他应用」，选择当前实际安装的 Node.js 程序

> 只为可信的专用网络放行；校园网、访客 Wi-Fi 可能隔离设备，放行后仍可能无法互访。

### 改完代码没生效

- 先看 PowerShell 窗口有没有**红色的报错**
- 有报错就把报错内容完整复制给别人看
- 没报错但界面没变，在浏览器按 `Ctrl + F5` 强制刷新

### 预览打包后的成品

```powershell
pnpm build
node scripts/serve-dist.mjs 4173
```

打开终端实际显示的地址。端口被占用或 IP 变化时，以当前输出为准。离线测试要针对构建版本。
