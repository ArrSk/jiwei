## 一、字义

### 几（jī，阴平）

**本义是"微"** ——《说文解字》：「几，微也。」

但在先秦典籍里，**「几」最要紧的一层意思不是"微小"，而是"事情将要发动而未发动的那个临界点"**：

- 《易·系辞下》：「**几者，动之微，吉之先见者也。**」
  ——「几」是"动"的最初征兆，是吉凶尚未成形、还能有所作为的那一瞬。
- 《易·系辞下》：「**知几其神乎！**……君子见几而作，不俟终日。」
  ——能觉察到"几"的人近乎神妙；君子看到苗头就行动，不等到天黑。
- 《易·系辞上》：「夫易，圣人之所以极深而研**几**也。」

「几」还可读 jǐ，表示"将近、几乎"（如"几近"），这一层也暗合"临界"之意。

### 微（wēi，阳平）

《说文》：「微，隐行也。」引申为：隐微、细微、将显未显。

### 几微（jī wēi）

「几微」是一个**成词的复音词**，古汉语中形容"细微的迹象、尚未显现的苗头"，
如《汉书》等史籍中「几微」用于指称事情的隐微端绪。

> 严谨起见：上面《易传》的引文是确凿的传世名句；「几微」作为固定词的确切出处与用例数目，
> 如果你将来要在正式文案里引用，建议再核一次《汉书》/《后汉书》原文，此处不虚构篇目。

## 二、为什么它适合这个产品

这个 App 做的是：**课表、日程、重要事件提醒、闹钟、笔记、待办**。

它的价值不在于"记录了多少事情"，而在于**在对的时刻让人知道该做什么**。
关键动作永远发生在那个微小的时间点：上课前十分钟、截止前一夜、事情还没耽误的最后一刻。

> **「几微」= 在最该被提醒的那一瞬。**

三层贴合：

| 层 | 对应 |
| --- | --- |
| **时间观** | 不追求"管理一生"，而是抓住那些微小的、将发未发的节点 —— 闹钟与提醒的哲学内核 |
| **日常感** | 大学生的日子由无数小事构成（一节课、一次作业、一场考试），本就该被"微"地照看，而非宏大叙事 |
| **分寸感** | 「知几」还有"恰到好处"之意：**提醒但不打扰**，这是提醒类产品最难也最该有的品质 |

而"知几"这个词本身，也正好是这个 App 想给人的感觉：**它知道那个时刻要到了。**

## 三、音、形、辨识度

- **音**：「几」阴平 + 「微」阳平，起音清亮、收音柔和，两字同属古微母系，**双声**，念起来连贯不生硬。
- **形**：笔画都少，两字都清瘦，视觉上内敛克制，符合"个人工具"而非"商业平台"的气质。
- **辨识度**：不是"时光""日程"这类已被用滥的词；小众但**不是生僻字**（几、微都是小学常用字），不需要用户查字典。
- **一个诚实的提醒**：「几」是多音字，首次接触可能被读成 jǐ。**产品首次露面时给一次注音**（几微 jī wēi）即可，之后不必再解释。

### 需要避开的近似词

| 词 | 说明 |
| --- | --- |
| 积微 | 荀子「积微成著」，词形相近但语义相反（积少成多 vs 抓临界点），文案中不要混用 |
| 极微 | 佛教/物理术语，且已有产品使用 |
| 機微（繁体） | 繁体写作「幾微」，注意字形不是「機」 |
